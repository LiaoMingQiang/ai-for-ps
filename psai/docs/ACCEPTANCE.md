# 真机验收清单

这份清单要在**真实的 Photoshop** 里执行。自动化测试已经覆盖了 Helper、作业引擎、
Provider 协议和内置工作流（见下方「已自动化的部分」），但下面这些只能在实机上验证：
UXP 面板能不能加载、图层能不能取出来、结果能不能写回正确的位置。

**未跑完这份清单，版本号不得标 1.0.0。** 没过的项如实记在文末，不许略过。

## 0. 环境准备

| 项 | 要求 | 本机实测 |
|---|---|---|
| Photoshop | 25.2.0 及以上 | Photoshop 2026 ✅ |
| UXP Developer Tool | 已安装 | ✅ |
| ComfyUI | 运行中，默认 `127.0.0.1:8188` | 0.30.1 · 3026 节点 ✅ |
| 显卡 | 有 CUDA 卡更好，没有也能跑（慢） | RTX 4070 Ti SUPER 16GB ✅ |

### 装 Helper

```bash
psai/release/AI-for-PS-Setup.exe
```

装完确认：

- [ ] 任务管理器里有 `AI-for-PS-Helper.exe`
- [ ] 浏览器打开 `http://127.0.0.1:34117/v1/health` 返回 `"online": true`
- [ ] 注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下有 `AIforPSHelper`

### 加载插件

1. 打开 UXP Developer Tool → Add Plugin → 选 `psai/packages/plugin/manifest.json`
2. 点 Load
